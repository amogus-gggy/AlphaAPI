# Tutorials

Learn AlphaAPI by building real projects. Each tutorial is self-contained and
uses only the framework plus the Python standard library unless stated
otherwise.

## Before you begin

If you have not installed AlphaAPI yet, follow
**[Getting started](../getting-started.md)** first.

All tutorials assume you are inside an activated virtual environment and that
the `alphaapi` command is available.
